Buka Folder images/

Klik tombol di bawah untuk memberi akses ke folder images/ di dalam folder website Anda. Browser akan meminta izin — klik "View Files" atau "Pilih" untuk melanjutkan.

Setelah itu, semua slot gambar akan tampil lengkap dengan status mana yang sudah ada dan mana yang masih kosong. Klik kartu gambar mana saja untuk langsung pilih file dari komputer dan disimpan otomatis ke folder yang benar.

info
Hanya tersedia di Chrome / Edge. Fitur "File System Access API" belum didukung Firefox dan Safari. Jika menggunakan browser lain, gunakan cara manual (copy file ke folder images/ biasa).
